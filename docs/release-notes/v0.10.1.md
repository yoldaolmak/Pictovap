# Pictovap 0.10.1

Pictovap 0.10.1 makes the visual diversity guard easier to review.

## What changed

`planning_diagnostics.similarity_pairs` now identifies each selected candidate
pair that crossed the configured similarity threshold. Each entry contains the
two candidate IDs, their similarity ratio, and the penalty applied to the
assignment objective.

This is an additive patch release. Existing adapters and consumers remain
compatible; consumers may ignore the new diagnostic field.

## Upgrade

```bash
python -m pip install --upgrade pictovap==0.10.1
```

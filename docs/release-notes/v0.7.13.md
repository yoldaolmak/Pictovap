# Pictovap 0.7.13

Pictovap 0.7.13 removes one more manual edit from external validation reports.

## Changed

- `pictovap feedback --plan my-plan.json --format markdown` now includes coarse
  OS metadata automatically beside the Pictovap and Python versions.
- External validation docs now describe the generated OS/Python metadata as
  safe runtime context, while continuing to exclude article text, private paths,
  image URLs, profile names, and credentials.

## Validation

- Main CI passed on Python 3.10, 3.11, 3.12, 3.13, and 3.14.
- Standalone adapter packages passed install, discovery, conformance, and wheel
  checks.
- CodeQL, dependency review, Scorecard, markdownlint, flake8, pyright, and the
  unit suite passed before release tagging.

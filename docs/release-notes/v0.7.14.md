# Pictovap 0.7.14

Pictovap 0.7.14 publishes the external validation issue-form flow to PyPI
users.

## Changed

- `pictovap feedback --plan my-plan.json --format markdown` now includes the
  dedicated external validation issue-form link.
- README and validation docs now ask testers to open a new external validation
  issue instead of posting under a shared tracking issue. This makes real
  downstream reports easier to count, triage, and review without exposing
  private article text, paths, image URLs, profile names, or credentials.

## Validation

- Main CI passed on Python 3.10, 3.11, 3.12, 3.13, and 3.14 before release
  preparation.
- Standalone adapter packages passed install, discovery, conformance, and wheel
  checks before release preparation.
- CodeQL, dependency review, Scorecard, markdownlint, flake8, pyright, and the
  targeted feedback/docs tests passed before release preparation.

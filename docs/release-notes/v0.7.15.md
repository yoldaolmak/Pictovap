# Pictovap 0.7.15

## Added

- `pictovap ecosystem explain` lists supported adjacent project categories.
- `pictovap ecosystem match` generates a reusable integration packet for a
  target project, including:
  - README section;
  - pull-request body;
  - workflow commands;
  - anti-spam checklist.
- Ecosystem integration documentation now explains where Pictovap fits beside
  Markdown-to-WordPress importers, AI draft tools, media upload scripts,
  Gutenberg tools, CMS automation, and static-site migration tools.
- A Markdown-to-WordPress pre-publish workflow example shows how to run
  Pictovap before the final WordPress import or publish step.

## Verification

- Focused CLI and ecosystem tests pass.
- Markdown documentation lint passes.

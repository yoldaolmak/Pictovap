# Pictovap 0.9.0

Pictovap 0.9.0 makes publisher metadata part of the visual planning contract.
Markdown authors can now describe editorial context once, and the planner
keeps it available to adapters, reports, and deterministic image scoring.

## What changed

- Added safe YAML frontmatter parsing for Markdown Visual Brief inputs.
- Exposed JSON-safe metadata as `visual_brief.frontmatter`.
- Added built-in mapping for `title`, `topic`, `location`, `avoid_list`, and
  `editorial_notes`.
- Included `tags`, `categories`, `audience`, and `location` in candidate
  relevance context.
- Rendered frontmatter context in Markdown editor reports.
- Invalid, missing, or non-mapping frontmatter remains fail-safe and does not
  prevent ordinary Markdown parsing.

## Upgrade

```bash
python -m pip install --upgrade pictovap==0.9.0
```

The change is backward-compatible: articles without frontmatter produce the
same Visual Brief shape, with an empty `frontmatter` mapping.

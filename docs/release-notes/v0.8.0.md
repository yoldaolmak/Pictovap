# Pictovap 0.8.0

Pictovap 0.8.0 strengthens the core planning engine with global, explainable
image assignment.

## Core change

Fit Scores are still calculated per candidate and slot, but the final choice is
now made across the complete article. The deterministic assignment engine
maximizes total fit while avoiding candidate reuse by default. If the provider
does not return enough eligible images, the plan remains safe and reports the
unfilled slots instead of masking the gap.

## New public surface

- `SelectionPolicy`
- `SelectionResult`
- `select_assignments()`
- `planning_diagnostics` in every generated plan

The change is dependency-free, covered by focused unit tests, and compatible
with existing plan fields, reports, and CMS adapter payloads.

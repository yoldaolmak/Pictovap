# ActoVisio Framework v0.14.0

The new canonical distribution is `actovisio-framework`, the Python namespace
is `actovisio_framework`, and the CLI is `actovisio-framework`. The previous
published `pictovap` 0.13.0 remains available. A separate matching compatibility
wheel preserves old imports and CLI without owning canonical files.

Existing MIT rights, schema and entry-point identifiers, and historical
provenance remain unchanged. Release and Product acceptance are separate.

# Pictovap 0.10.0

Pictovap 0.10.0 adds a core editorial diversity guard. The planner can now
recognize near-duplicate images before a visual plan reaches CMS placement,
while remaining deterministic, offline, and compatible with existing
adapters.

## What changed

- Local image sources compute a compact perceptual fingerprint when a file is
  already available on disk.
- External adapters can provide the optional `visual_fingerprint` field.
- The global assignment engine applies a transparent similarity penalty when
  two selected candidates are visually too close.
- Plan diagnostics now include `adjusted_total_score` and
  `diversity_penalty`.
- Missing fingerprints are ignored; Pictovap never downloads remote assets
  only to calculate similarity.
- The requests dependency floor is now installable from the public package
  index (`>=2.32.3`).
- The Pillow dependency floor is now installable from the public package index
  (`>=10.4.0`).

## Upgrade

```bash
python -m pip install --upgrade pictovap==0.10.0
```

The change is backward-compatible. Existing adapters continue to work without
any changes and retain the previous assignment behavior when they do not
provide fingerprints.

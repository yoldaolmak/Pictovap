# Pictovap v0.13.0

> Status: prepared development release. It is not published to PyPI yet; the
> current stable release is [0.12.0](https://pypi.org/project/pictovap/0.12.0/).

Pictovap 0.13.0 adds a plan-audit boundary for teams that need to review or
gate a visual plan before a CMS adapter runs.

## Plan audit

```bash
pictovap audit --plan output/visual-plan.json --format markdown
pictovap audit --plan output/visual-plan.json --strict
```

The audit is local and read-only. It combines the structural validator with
coverage, provenance/license, accessibility, human-review, and duplicate
selection checks. JSON is intended for CI; Markdown is intended for an editor
or a pull request review.

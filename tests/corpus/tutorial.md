# Build a Reliable Editorial Checklist

A short checklist helps an editor review structure, links, images, and publishing details.

## Start with the Article Goal

Write the intended reader and outcome at the top so every later decision has context.

## Review the Content Structure

Check headings, paragraphs, examples, and links for a clear sequence before choosing images.

## Check Image Requirements

Confirm each image has a useful role, accessible alternative text, and recorded provenance.

## Prepare the Publishing Handoff

Verify the target CMS fields, placement instructions, and final report before publishing.
